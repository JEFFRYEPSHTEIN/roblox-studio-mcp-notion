Скачайте Windows amd64 cloudflared из официальных релизов:

https://github.com/cloudflare/cloudflared/releases

Переименуйте файл `cloudflared-windows-amd64.exe` в `cloudflared.exe` и поместите сюда.
Если cloudflared уже доступен через PATH, копировать его сюда не требуется.
Бинарный файл исключён из Git и архива исходников.
